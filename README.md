## 🛠️ Como rodar localmente

```bash
# Clone o repositório
git clone https://github.com/SposatoDev/chronos-pomodoro.git
cd chronos-pomodoro

# Instale as dependências
npm install

# Rode em modo de desenvolvimento
npm run dev

# Build para produção
npm run build
